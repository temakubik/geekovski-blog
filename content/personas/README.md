# Паспорта персонажей GEEKOVSKI

Редакция канала ВКонтакте. Три человека, от чьего лица идут посты: **Сева** (железо, цифры), **Марк** (игры), **Аня** (кино и сериалы). Голос каждого отличается не только темами, но и манерой — это и есть смысл: читатель должен узнавать автора по абзацу.

## Зачем паспорт

Паспорт — это канон. Один и тот же человек на обложке поста, в аватарке и в картинке через месяц. Поэтому внешность описана **дословными формулами**, а не «тёмные волосы, очки, худи»: если каждый раз описывать заново, модель нарисует трёх разных людей.

- `anchor` — короткая формула внешности на английском. Копируется в каждый промпт **без изменений**, к ней добавляется только сцена.
- `style` — общий фотографический стиль редакции: один для всех троих.
- `negative` — чего в кадре быть не должно (текст, логотипы, водяные знаки, 3D-рендер).

## Общий стиль картинок

Редакционный кадр, не сток и не рендер: плёночная фотография 35 мм, мягкий направленный свет, приглушённая палитра, лёгкое зерно, небольшая глубина резкости, естественная кожа без ретуши. Техника в кадре настоящая и старая, а не «футуристичная».

Правило для всех: **никакого текста на картинке.** Ни подписей, ни названий, ни интерфейсов с читаемыми буквами. Текст ставит шаблон, а не генератор.

## Как генерировать

Сейчас генерация идёт **через Doop MCP** (`generate_image`, списывается квота ChatGPT): аспект `square` для аватарки, `landscape` для кадра в посте. Промпт = сцена из паспорта + `anchor` + `style` + `negative`, дословно.

```
# сохранить готовый кадр из Doop в нужную папку
python3 tools/gen_persona.py --save-url https://doop.design/a/XXXX.webp --slug seva --shot avatar
```

Резервный путь — `tools/gen_persona.py` через OpenAI Images API (модель `gpt-image-2.5-sunburst`):

```
python3 tools/gen_persona.py --slug seva --shot avatar
python3 tools/gen_persona.py --slug all --shot avatar
python3 tools/gen_persona.py --slug mark --shot desk --dry-run   # только промпт
```

⚠️ Ключ `OPENAI_API_KEY` в профиле **просрочен** — этот путь включится, когда будет новый ключ.

Ручная генерация в любом сервисе — тот же принцип: `anchor` + сцена из паспорта + `style` + `negative`, дословно.

## Главная техническая заноза: лицо плывёт между кадрами

Текстовый промпт держит лицо примерно, но не точно: на первой генерации Марк в кадре «за игрой» вышел другим человеком — другой овал лица, тяжелее фигура. После переделки паспорта (41 год, борода, полнота) оба кадра сошлись, но правило остаётся:

- **канон — аватарка** (`img/<slug>/avatar.jpg`). Она же идёт в профиль сообщества и в карточки авторов;
- остальные кадры с человеком **генерируются по референсу**: аватарка подаётся модели как входная картинка (OpenAI `images.edit` либо Gemini-модель с image-input на OpenRouter — нужен новый ключ или кредиты);
- пока референса нет — не плодим кадры с персонажем, а берём один канон и общие планы без лица (руки, стол, экран, зал).
