# SMM-контур сообщества ВК — как это работает

Сообщество: **GEEKOVSKI**, `vk.com/geekovskiread`, id `243393964`.
Публикация постов живёт в `tools/vk_publish.py`, аналитика и общение — в `tools/vk_smm.py`,
раскладка дня — в `tools/vk_daily.py`, сессия пользователя — в `tools/vk_session.py`.

## Что ВК отдаёт, а что нет

Проверено на живом сообществе 18.11.2026.

| Задача | Метод | Ключ | Итог |
|---|---|---|---|
| опубликовать пост / отложка | `wall.post` | сообщества | да |
| ответить в комментариях, скрыть коммент | `wall.createComment` / `deleteComment` | сообщества | да |
| события в реальном времени | `groups.getLongPollServer` | сообщества | да |
| личные сообщения сообщества | `messages.*` | сообщества (`messages`) | да |
| подписчики, счётчики | `groups.getById` | сообщества / сервисный | да |
| посты с лайками, комментами, репостами | `wall.get` | **сервисный** | да |
| комментарии к постам | `wall.getComments` | **сервисный** | да |
| загрузить фото, править и удалять посты, закреп | `photos.getWallUploadServer` / `saveWallPhoto` / `wall.edit` / `wall.delete` / `wall.pin` | **пользователя** (сессия из браузерного профиля) | да |
| охваты, источники, демография | `stats.get` | **пользователя, недоступен** | **нет** |

Две дырки и один обход:

- **`stats.get` требует ключ пользователя с правом `stats`**, а такой обычным путём не
  выдают (Implicit Flow закрыт с 25.06.2024). Охваты и источники смотрим глазами в
  `vk.com/stats?gid=243393964`. Подписчиков, лайки, комменты, репосты и просмотры API
  отдаёт — это основной массив SMM-цифр.
- **Вложение-ссылка не работает.** `wall.post` с URL в `attachments` отбивает
  `error 100: Violated: link_photo_sizing_rule. No photo given` — на любой домен.
  Поэтому схема поста: карточка-фото вложением + ссылка строкой в тексте.
- **Фото грузятся только сессией пользователя.** Ключ сообщества получает ошибку 27 на
  `getWallUploadServer`, а доступный ему `saveMessagesPhoto` кладёт снимок в приватный
  альбом «Сохранённые» — оттуда к стене его не прикрепить. Сессия берётся из
  `tools/vk_session.py` (web_token веб-клиента из localStorage браузерного профиля
  `browser-profiles/vk`, CDP 9337). Браузер нужен только чтобы один раз войти.

## Ключи и сессия

`~/.hermes/profiles/geekovski/.env` (chmod 600):

- `VK_GROUP_ID` — числовой id сообщества;
- `VK_GROUP_TOKEN` — ключ сообщества (стена, комменты, Long Poll, ЛС);
- `VK_SERVICE_TOKEN` — сервисный ключ Standalone-приложения (чтение стены и комментов).

Плюс `~/.hermes/profiles/geekovski/.vk_web_token.json` — кэш сессии пользователя,
обновляется сам: `python3 tools/vk_session.py` проверяет и достаёт свежий.

Проверка: `python3 tools/vk_smm.py check`.

## Команды

```
python3 tools/vk_smm.py check                  # какие ключи живы
python3 tools/vk_smm.py audit --limit 30       # снимок: подписчики + посты → content/vk/state/snapshots.jsonl
python3 tools/vk_smm.py report --days 7        # отчёт с дельтами (markdown)
python3 tools/vk_smm.py members --days 30      # динамика подписок по снимкам
python3 tools/vk_smm.py comments --new         # новые комментарии с прошлого раза
python3 tools/vk_smm.py reply --post-id 12 --comment-id 34 --text "…"   # черновик; --send — отправить
python3 tools/vk_smm.py poll --wait 25         # события: комментарии, подписки, ЛС

python3 tools/vk_publish.py --slug <slug> --photo auto --dry-run            # черновик поста
python3 tools/vk_publish.py --slug <slug> --photo auto --publish-at "18:30" # отложка
python3 tools/vk_daily.py [--apply]            # три отложки на день из свежих статей
```

`--photo auto` берёт `cover` из frontmatter, собирает карточку 1080×1350 с логотипом
(`make_vk_post_card.py`), пересохраняет и заливает в альбом сообщества. `--no-card` —
приложить кадр как есть.

## Рабочий цикл

| Когда | Что |
|---|---|
| 08:45, крон `vk-posts-daily` | `vk_daily.py --apply`: три отложки на 09:30 / 13:30 / 19:30 (окно свежести 3 дня, занятые слоты пропускаются) |
| 11:00 и 20:00, крон `vk-smm-digest` | `poll` + `comments --new` + `audit`: что пришло в комментариях и в подписках, черновики ответов |
| в течение дня | ответ на комментарий: черновик → «да» автора → `reply --send` |
| по понедельникам 12:00, крон `vk-smm-weekly` | `report --days 7` + `members --days 30`: подписчики, реакции, ER, топ и провалы, выводы |
| раз в неделю глазами | `vk.com/stats?gid=243393964`: охваты, источники, демография |

Ритм: **3 поста в день** (09:30, 13:30, 19:30 МСК). Ссылки на статьи блога — около 60%
постов, посты от лица персонажей — 30%, опросы и вопросы — 10%.

## Регламент общения

- Отвечаем от имени сообщества, подпись — как в постах (`— Сева`, `— Марк`, `— Аня`).
- Вопрос по делу → ответ в тот же день. Хамство и спам → скрыть, не спорить.
- Ошибку в своём материале признаём сразу и правим статью.
- Спорные темы в комментариях не разгоняем, эскалируем автору.
- Новому подписчику первым в личку не пишем.

## Чего в контуре нет

- **Реклама и таргет** — отдельный кабинет VK Ads.
- **Автопостинг из RSS** — ВК умеет сам, но не фильтрует и не растягивает записи; скриптовый
  маршрут точнее. Отдельный фид `/vk.xml` собирается в `build.py`, но импорт решает автор.
- **Лайки как события** — Long Poll их не отдаёт, реакции считаются снимками.

## Правило публикации

Реальный пост в живое сообщество — только после явного «да» автора. Черновик, отложка и
тестовая группа — без вопросов.
