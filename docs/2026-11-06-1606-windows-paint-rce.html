Paint в Windows 11 уязвим, а исправление не доехало

Microsoft закрыла 13 октября удалённое выполнение кода в Paint (CVE-2026-83844, 8,1 из 10), но обновление идёт только через Microsoft Store — и у части пользователей с включённым автопатчем осталась старая сборка. Проверить версию можно одной командой в PowerShell.

Коротко

  • CVE-2026-83844 — чтение за границей буфера в Paint, позволяет выполнить код по сети без авторизации и действий пользователя; CVSS 8.1, уровень Important
  • Исправленная сборка — 11.2609.401.0; сначала Microsoft называла 11.2605.91.0, которой в магазине никогда не было
  • Paint обновляется через Microsoft Store, а не через Windows Update: полностью обновлённая Windows 11 может остаться с дырой
  • Сообщений о реальных атаках нет, эксплуатация требует глубокого понимания системы

У встроенного в Windows 11 Paint нашлась уязвимость, которую Microsoft закрыла ещё 13 октября, — но патч больше месяца не доезжал до части машин. Речь о CVE-2026-83844: чтение за границей выделенного буфера (CWE-125), из-за которого атакующий может выполнить произвольный код. Оценка по CVSS 3.1 — 8,1, уровень Important. В описании Microsoft сказано, что атака идёт по сети и не требует ни аутентификации, ни действий пользователя.

Именно последнее переводит историю из «ещё один патч вторника» в неприятную: Paint получает обновления не через Windows Update, а отдельным пакетом из Microsoft Store. То есть машина с полностью установленными октябрьскими кумулятивными обновлениями Windows 11 может оставаться с уязвимым редактором — обновление системы его не касается.

Отдельная путаница — с номером сборки. Изначально Microsoft указала исправленной версию 11.2605.91.0, но в публичном каталоге Store такой сборки не было вовсе: администраторы обновлялись и упирались в 11.2605.81.0. В начале ноября Microsoft поменяла в Security Update Guide цифру на 11.2609.401.0, не добавив записи в историю ревизий, а в самой карточке CVE и в NVD по-прежнему фигурирует старый порог. Пока обе планки на практике отсекают одни и те же ПК, но сканеры, читающие карточку CVE, могут считать уязвимую сборку исправленной.

5 ноября издание Windows Latest проверило машину с включённым автообновлением и нашло Paint сборки 11.2603.251.0 — задолго до патча. Брайан Витко из RFF на этой неделе смотрел, какие версии предлагает Store в шести странах, и везде видел 11.2605.81.0. The Hacker News сегодня проверила десять стран и во всех получила уже 11.2609.401.0 — то есть исправление начало расходиться, но проверить конкретный компьютер всё равно придётся вручную.

Проверка — одна строка в PowerShell от администратора: Get-AppxPackage -AllUsers -Name Microsoft.Paint, в выводе нужна версия 11.2609.401.0 или новее. Если ниже — открыть Store, раздел «Загрузки» и нажать «Получить обновления»; для парка машин то же делается через Intune или winget с идентификатором 9PCFS5B6T72H.

Статус инфоповода: уязвимость официально раскрыта Microsoft, исправление официально выпущено, подтверждённых атак нет — в карточке CVE эксплуатация отмечена как не обнаруженная, а сама Microsoft пишет, что успешная атака требует глубокого понимания целевой системы. То есть это не пожар, а гигиена: обновить небольшое приложение, которое годами живёт отдельно от системы и поэтому выпадает из привычного «поставил обновления — закрыл вопрос».

Мнение: самая интересная часть истории — не сама дыра, а то, как Microsoft обращается с исправлением. Смена номера сборки без ревизии в бюллетене и патч, который месяц не виден в магазине, — это проблема процесса, а не кода. И она повторится: чем больше частей Windows живёт в Store, тем чаще «всё обновлено» будет означать не то, что мы думаем.
