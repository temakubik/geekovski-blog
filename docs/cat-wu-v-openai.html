Cat Wu перешла из Anthropic в OpenAI

Продакт-лидер Claude Code Кэт Ву, ушедшая из Anthropic на прошлой неделе, объявила о переходе в OpenAI — она возглавит продакт-менеджмент основных продуктов. Это за две недели до IPO Anthropic.

Коротко

  • Кэт Ву вела продуктовую часть Claude Code — от внутреннего прототипа до коммерческого продукта
  • В OpenAI она будет отвечать за продакт-менеджмент Core Products и подчиняться Тибо Соттио
  • OpenAI переход подтвердила, Anthropic от комментариев отказалась
  • Уход случился примерно за две недели до планируемого IPO Anthropic

Кэт Ву, которая вела продуктовую сторону Claude Code в Anthropic, объявила 5 ноября, что переходит в OpenAI. Пост она выложила у себя в X: «Присоединяюсь к OpenAI, чтобы возглавить продакт-менеджмент основных продуктов». Business Insider пишет, что OpenAI переход подтвердила, а Anthropic от комментариев отказалась — то есть это не слух и не утечка, а подтверждённый нанимателем переход.

В Anthropic Ву отвечала за продукт Claude Code — инструмента, который вырос из внутреннего прототипа в коммерческий продукт и во многом сделал репутацию компании в разработке. Из Anthropic она ушла на прошлой неделе, а об уходе объявила во вторник, 3 ноября.

В OpenAI Ву будет подчиняться Тибо Соттио и работать с Ником Тёрли по корпоративным продуктам и Эшли Александер по потребительским. Формулировка в её посте — про агентов: «будем строить агентов, которые прикрывают вас и вашу команду и оставляют контроль вам».

Контекст, в котором это читается громче обычного найма: Codex, прямой конкурент Claude Code, в этом году отстал от Anthropic по корпоративным продажам, и усиление продакт-команды — очевидная попытка выправить именно эту часть. Сам переход случился примерно за две недели до планируемого IPO Anthropic, когда компания рассказывает инвесторам историю роста.

Это не первый раз, когда Ву уходит из Anthropic к конкуренту: в 2025-м она вместе с создателем Claude Code Борисом Черни перешла в Cursor, но быстро вернулась обратно — об этом писал The Information.

Оценка: для OpenAI это в первую очередь сигнал рынку, что продуктовая школа Claude Code теперь работает на Codex, а не прибавка к штатному расписанию. Для Anthropic — неприятный фон перед IPO: уход человека, чьё имя в индустрии ассоциируется с самым успешным продуктом компании, приходится объяснять инвесторам.
